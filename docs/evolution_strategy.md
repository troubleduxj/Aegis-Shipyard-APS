# 十亿美元级工业级排程与中控系统 (Aegis Shipyard APS & Command) 逐步演进战略规划书

本规划书旨在为面向重工业、大型船舶造船等复杂场景的**十亿美元级先进排程（APS）与数字化智能中控平台**规划由浅入深的四个生命周期开发与商业化演化阶段。通过本规划，项目团队可从单机或单点突破开始，逐步发展成支撑全球供应链与海量物联网高并发、融合 AI 深度决策的航母级企业服务生态。

---

## 总体路线图 (Evolution Roadmap Overview)

```
阶段一 (0 -> 1): 最小可行性产品 (MVP) 与单核心求解
      |
      └───> 阶段二 (1 -> 10): 企业级集成、微服务化与多源混合数据
            |
            └───> 阶段三 (10 -> 100): 工业孪生、AI 智能体 (Agent) 闭环调度
                  |
                  └───> 阶段四 (100+): 跨国供应链协同生态、SaaS 化与低代码平台 (十亿美元级终局)
```

---

## 阶段一：核心突破与 MVP 验证 (0 到 1 阶段)
**目标**：验证核心业务逻辑、建立产品信誉、切入标杆客户单点痛点。

### 1. 软件架构设计
*   **架构形态**：采用响应式单页客户端 (SPA) + 模块化单体服务后端 (Modular Monolith)。此时不建议引入复杂的微服务网格，优先保证快速迭代。
*   **计算硬核 (Core Engine)**：开发单机高性能排程算法，采用启发式算法（Heuristics）、遗传算法 (Genetic Algorithm) 或混合整数线性规划 (MILP) 解决干船坞、滑道与主要班组的冲突。
*   **信息源管理**：支持 CSV/Excel 批量导入，提供本地缓存机制（如 `localStorage` 或 IndexedDB）进行临时排程结果保存。

### 2. 功能特征与核心控制
*   支持单项目船舱及主要里程碑 (Gantt Chart) 交互编辑及拖拽调整。
*   钢体车间、焊接班组等瓶颈资源的单维负载监视。
*   基础实时日志（通过长轮询或单通道 SSE 同步信号）及基础指令查询（如简单的规则匹配）。

### 3. 本阶段里程碑指引
*   在 1 家标杆造船厂的 1 个主要船坞/码头试运行成功。
*   排程效率较传统人工手工排单（Excel）提升 **50%** 以上。

## 阶段二：企业级集成、微服务与高可用中控 (1 到 10 阶段)
**目标**：打破数据孤岛，与 ERP、MES、PLM 等巨型软件集成，进入多物理区域和企业级并发阶段。

### 1. 软件架构设计
*   **业务架构**：全面过渡到微服务（Microservices）架构。采用 API 网关 (Kong / Spring Cloud Gateway) 进行鉴权与流量调度。
*   **混合存储引擎 (Hybrid Storage)**：
    *   **关系型数据库**（如 Postgres / MySQL）处理复杂的配置、物料 B0M 和班组台账。
    *   **时间序列数据库**（如 InfluxDB / TDengine）存储车间行吊、焊接机、AGV 的海量物联网指标。
    *   **高性能缓存**（Redis）维护排程快照与实时流数据。
*   **安全与合规**：引入基于 OAuth2 / SAML 的企业单点登录 (SSO) 与精细化角色权限控制 (RBAC)。

### 2. 功能特征与核心控制
*   **多源集成**：打通与 SAP / Oracle (ERP)、Teamcenter (PLM) 的实时接口，船体三维模型（BOM 结构）自动反写为工程排班任务。
*   **动态求解中心**：引入分布式计算队列（基于 RabbitMQ / Kafka 配合 Celery / Ray），支持复杂条件下的多级寻优算法。

### 3. 本阶段里程碑指引
*   签约多于 10 家大型工业集团。
*   系统支持 **10,000+** 实时控制点和 **100+** 班组并发协作。

## 阶段三：AI Agent 深度融合、物理数字孪生 (10 到 100 阶段)
**目标**：将系统从“记录和建议工具”转变为“具备部分自治权的智能指挥中枢”。

### 1. 软件架构设计
*   **AI 智能决策总线 (AI Broker)**：
    *   引入大语言模型（如 Google Gemini API）与传统 APS 算法模型的混合联动。
    *   构建专有知识库（RAG 系统），将造船规范、特殊钢材焊接要求、港口泊位数排布规范注入 AI。
    *   不再是简单的文字问答，AI 拥有 Action Tool 的执行权。例如：当监测到原材料延期时，AI Agent 可通过分析直接触发“调用应急预案修改里程碑并重新请求排班求解”。
*   **数字孪生 (Digital Twin)**：结合 WebGL / Three.js 乃至 GIS 地图服务，构建三维实景堆场、船坞监控，实时把传感器数据叠加于物理实体上。

### 2. 功能特征与核心控制
*   **真正的智能指挥台**：调度长可使用自然语言进行极限工效质询与重排程指令（如“高强钢推迟 3 天，优化方案是什么？”），系统自动评估并生产多套求解选项对比。
*   **自动预警闭环**：结合物联网监控，自动预测瓶颈（如“根据现有工速，No.2 船体合拢可能延误 4 天，建议今晚调拨班组 B 支援”）。

### 3. 本阶段里程碑指引
*   实现全厂生产决策 **30% - 40%** 的全自驱或 AI 辅助自适应优化。
*   系统能够在一分钟内重算万级工序关联的全局计划。

## 阶段四：行业平台、跨国协同生态与 SaaS 平台 (100+ 终局阶段)
**目标**：确立行业绝对标准，构建横跨业主、主包商、分包商、物流商和检测机构的十亿美元级产业上下游网络（Ecosystem Platform）。

### 1. 软件架构设计
*   **多租户 SaaS 架构**：采用云原生（Kubernetes）完全弹性底座。租户数据高安全隔离（采用行级隔离或完全独立模式的物理数据库）。
*   **全球化边缘计算 (Edge & Mesh)**：全球化数据中枢，支持多船厂、多国家法律、多时区协同，采用本地边缘集群（Edge Node）离线工作、同步上云机制。
*   **低代码开发者平台 (PaaS)**：开放 API 并推出可视化工作流引擎，允许造船厂自己的 IT 团队、第三方系统集成商根据自身特定流程（如潜艇建造、海上钻井平台建造）定制规则、UI 控件。

### 2. 功能特征与核心控制
*   **供应链纵向协同**：系统直接连接上游钢厂（自动跟踪 EH36 钢材从出炉、内河集运到进港的全流程），同步连接下游航运业主（实时展示建造进度以激活阶段付款流程）。
*   **生态链共享经济**：提供“码头/龙门吊共享闲置产能撮合交易功能”，使临近船厂实现产能和昂贵重工业设备（如 1000t 龙门吊）的跨厂域协同租赁。

### 3. 本阶段里程碑指引
*   全球主要的头部船厂及供应链伙伴全面入驻平台。
*   平台交易及产业订阅（SaaS/PaaS）年营收达到 **1亿美元** 以上，支撑起百倍估值的**十亿美元级工业软件独角兽生态**。

## 行动指南：如何从 Aegis Shipyard APS 的现状开始？

我们目前拥有一个由 React 和 Tailwind 驱动、内置了轻量级求解推荐和 Gemini AI 智能提问台的中控雏形（属于**阶段一**的高端形态）：

1.  **首要切入点**：固化当前的排程展示与 AI 智能提问台（我们已经实现了可折叠隐藏的极佳交互设计，不影响图表查看）。
2.  **下一步行动**：
    *   将模拟的求解算法剥离至独立的后端服务中。
    *   引入一个真实的 Postgres 或类似的开发用轻量级数据库，持久化存储多个船舶工程的里程碑历史数据。
    *   编写标准的持久化 REST API 端点，替代目前单纯的内存 React 数组状态。
